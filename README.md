### Explanation

Digital learning platforms have transformed the way students access educational content. Online learning systems provide video lectures, assignments, assessments, and discussion forums that allow students to learn remotely at their own pace.

Artificial intelligence and structured prompts can be used to generate explanations, comparisons, and learning support related to online education systems. Different prompt types help produce responses with varying levels of detail, clarity, and perspective.

### Scenario

A university is implementing an online learning platform to support students who cannot attend traditional classroom sessions. The platform includes recorded lectures, quizzes, progress tracking, and discussion forums.

Target users include:

University students

Instructors delivering online courses

Educational institutions adopting digital learning tools

### Procedure and Prompt Examples
**1. Comparative Analysis Prompt**

This prompt type focuses on comparing two different systems or approaches.

Prompt Example

“Compare traditional classroom learning with online learning platforms in terms of accessibility, flexibility, and student engagement.”

Expected Response

• Traditional classroom learning requires physical presence and fixed schedules.
• Online learning platforms allow students to access lessons anytime and from any location.
• Digital platforms provide recorded lectures, interactive quizzes, and flexible study schedules.

**2. Experiential Perspective Prompt**

This prompt asks the response from a personal or professional viewpoint.

Prompt Example

“Imagine you are a university student using an online learning platform for the first time. Describe how it helps you manage your studies more effectively.”

Expected Response

• Explanation from a student's perspective.
• Ability to watch recorded lectures multiple times.
• Easy access to study materials and assignments.
• Improved time management due to flexible schedules.

**3. Everyday Functioning Prompts**

These prompts simplify complex ideas by connecting them to everyday experiences.

Prompt Example

“Explain how an online learning platform works by comparing it to everyday tools such as video streaming apps or digital note-taking applications.”

Expected Response

• Watching lectures is similar to streaming videos on platforms like video apps.
• Submitting assignments online is similar to uploading files in cloud storage.
• Notifications remind students about deadlines similar to calendar alerts.

**4. Universal Prompt Structures**

This prompt type encourages clear, structured explanations.

Prompt Example

“Explain how an online learning platform helps students complete a course using simple steps.”

Expected Response

Students register and enroll in a course.

They access recorded lectures and learning materials.

Assignments and quizzes are completed online.

The system tracks progress and provides results.

**5. Prompt Size Limitations**

Large prompts may produce lengthy responses, so they can be divided into smaller prompts for clarity.

Large Prompt Example

“Explain how online learning platforms improve education through course delivery, student interaction, and progress tracking.”

Refined Smaller Prompts

• “Explain how online platforms deliver course materials to students.”
• “Describe how students interact with instructors in online learning systems.”
• “Explain how online learning platforms track student progress.”

Expected Response

• Separate explanations for each function of the platform.
• Clear and focused responses for better understanding.

### Result

After applying different prompt engineering techniques, it was observed that:

• Comparative prompts help evaluate different learning methods.
• Experiential prompts provide user-centered insights.
• Everyday prompts simplify technical explanations.
• Universal prompt structures create clear step-by-step responses.
• Prompt size limitations help manage complex topics effectively.

### Conclusion

Various prompt engineering techniques were successfully applied to the online learning platform scenario. Choosing appropriate prompt structures improves the clarity and quality of AI-generated responses, which is useful for explaining modern digital education systems.
