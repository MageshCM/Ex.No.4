## Aim
To generate and evaluate different prompting techniques such as **Comparative Analysis Prompt**, **Experiential Perspective Prompt**, **Everyday Functioning Prompt**, **Universal Prompt Structures**, **Prompt Refinement**, and **Prompt Size Limitations** using an Artificial Intelligence tool.

## AI Tool Used
**ChatGPT (OpenAI Generative AI Tool)** Used to create and test prompts based on different prompting techniques and to observe the responses generated by the AI system.

---

## 💡 Prompting Techniques & Examples

### 1. Comparative Analysis Prompt
This prompt asks the AI to compare two or more items and explain similarities and differences.

**Example Prompt:**
> "Compare cloud computing and edge computing based on cost, speed, scalability, and real-world applications."

### 2. Experiential Perspective Prompt
This prompt asks the AI to explain something from a particular role, experience, or viewpoint.

**Example Prompt:**
> "Explain the advantages of cloud computing from the perspective of a small business owner."

### 3. Everyday Functioning Prompt
This prompt connects a technical concept to daily life or practical situations.

**Example Prompt:**
> "Explain how artificial intelligence is used in everyday life such as smartphones, online shopping, and navigation apps."

### 4. Universal Prompt Structures
These prompts follow a clear, highly structured format that works effectively for almost any topic.

**Example Prompt:**
> "Explain the concept of blockchain technology. Include its definition, working principle, advantages, disadvantages, and applications."

### 5. Prompt Refinements
This involves iteratively improving or modifying a prompt to obtain a more specific or higher-quality response.

| Version | Prompt Text |
| :--- | :--- |
| **Initial Prompt** | "Explain cloud computing." |
| **Refined Prompt** | "Explain cloud computing in simple words for beginners. Include its types, advantages, and real-world examples." |

### 6. Prompt Size Limitations
This focuses on controlling prompt length to observe the balance between brevity and detail for clarity and efficiency.

* **Short Prompt Example:** "Define artificial intelligence."
* **Detailed Prompt Example:** "Define artificial intelligence and explain its major applications in healthcare, education, and finance."

## 🏁 Conclusion
From this experiment, it is concluded that effective prompt design plays an important role in obtaining accurate and relevant responses from AI systems. Using structured prompting techniques improves clarity, enhances response quality, and allows users to interact with AI tools more efficiently.

## ✅ Result
The different prompting techniques—Comparative Analysis Prompt, Experiential Perspective Prompt, Everyday Functioning Prompt, Universal Prompt Structures, Prompt Refinement, and Prompt Size Limitations—were successfully tested using the AI tool. 

The AI generated meaningful and structured responses for each prompt type. The experiment demonstrated that the quality, clarity, and length of prompts significantly affect the accuracy and usefulness of the AI-generated responses.
